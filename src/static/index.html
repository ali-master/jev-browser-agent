Network filtering

Uses EasyList. Rules download once per server or CLI process when enabled; no page content is sent to the list provider.

Use full HTTP(S) URL patterns, with * for wildcards. Blocks matching requests and redirects in the agent's tab. Blocked links are also excluded from its choices.

Page cleanup

Removes matching elements from the main document before each analysis, including after navigation. Removing forms or scripts can break a task. It does not undo scripts that already ran.

Browser filters apply when you start a new task. All filters are off by default.

Keys stay on this computer and are sent only to the configured provider. Leave a key blank to retain it. Changing a Base URL clears its old key unless you enter a replacement.
