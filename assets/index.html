04 — A LITTLE LESS IN THE WAY

Less noise.
More room to think.

Give the agent a clearer page to work with. Block ad requests, exclude unwanted destinations, and remove the elements your task doesn't need.

01 / AD REQUESTS

Skip the distraction.

Enable EasyList network filtering to stop matching advertising requests before they load in the agent's tab.

  • Block ad requests Optional. Off by default.
02 / BLOCKED URLS

Choose what's off limits.

Set URL patterns to block matching requests and redirects. Matching links leave the agent's list of choices, too.

  • *://ads.example.com/* Your URL patterns. One per line.
03 / PAGE CLEANUP

Keep what matters.

Remove tags or elements by CSS selector before each observation, including after navigation and dynamic page updates.

  • aside.sponsored Clean up the main document before analysis.
04 / YOUR SETTINGS

Set it for the next run.

Save filters in Agent settings for the inspector, CLI and library. Or supply a filter configuration for one library run.

  • Start a task. Keep its rules. Saved changes apply to new tasks.

All filters are optional. EasyList downloads on first use in each process. Filtering covers the controlled tab; cleanup leaves frames and shadow roots alone. Keep the controls and scripts your task needs.

Bun 1.4.3+ · Chromium · Two model connections 

# Install the CLI globally
bun add --global @usex/jev-browser-agent
bunx --bun playwright@1.64.1 install chromium

# Open the inspector with detailed logs
jev serve --port 8766 \
  --log-level debug --log-detail high \
  --color auto

Use the model connections above. Switch to --color never for plain output, or --log-detail low for less detail. Debug logs separate browser and model timings. Save page filters in Agent settings; the CLI uses them for new tasks, too.

Use local endpoints or your cloud provider's URL and key. The chat helper must support JSON schemas. 

import { Agent } from "@usex/jev-browser-agent";

await using agent = await Agent.create(
  "https://en.wikipedia.org/wiki/Main_Page",
  "Find and open the article about Lisbon.",
  {
    filters: {
      blockAds: true,
      blockedUrls: ["*://ads.example.com/*"],
      removeSelectors: [".advertisement"],
    },
  },
);

for await (const state of agent.run()) {
  console.log(state.status, state.page.url);
}

Save as agent.ts, then run: bun run agent.ts. Replace the example patterns and selectors for your site. Omit filters to use saved settings, or pass filters: {} to disable them for this run.
